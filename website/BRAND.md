# Brand

## Name

**rimBaud**

- Public wordmark: `rimBaud`
- Desk chrome: `rimBaud  //  MATRIX`
- Chart chrome: `rimBaud  //  CHART`
- Binaries: `rimbaud-desk`, `rimbaud-chart` (old `freiquell-*` names still symlink)

Do not use Freiquell on the public site. That was the previous internal name.

## Voice

- Short sentences. Operator, not marketer.
- Prefer “does not close clips” over “safe and secure”.
- Prefer “unique Hyperliquid subaccount per hunter” over “bank-grade isolation”.
- No rocket emojis. The live desk uses a few functional icons (copy bolt, PMM grid). Keep them sparse.

## Audience

One human running a private Hyperliquid fleet: copy, market-make, SuperTrend, Elliot, short-the-bounce, DCA maker, only-up moon bags. They care about leftover USD, ROE, IP tokens, and not flattening a bag by accident.

- A Telegram signal shop
- An “AI hedge fund”
