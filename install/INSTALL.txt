rimBaud — one-command install
=============================

USB or folder with the tarball:

  sudo bash install.sh

That:
  1. unpacks rimbaud-install-*.tar.gz → /opt/rimbaud
  2. installs Docker, Copy hunter + dashboard, Spring :5004, desk
  3. joins the meta VPN if JOIN.conf is next to install.sh; opens 5004 on wg
  4. opens checkboxes (SPACE = OK, ENTER = finish, s = Copy master 0x)

New Hyperliquid account: Copy only for weeks of volume.
  Copy MASTER 0x  = the HL account you fund (not the API agent address)
  API secret      = 0x+64 from app.hyperliquid.xyz/API (agent of that master)
  vault           = OFF
  Then transfer USDC Spot → Perps on Hyperliquid or Copy equity stays $0.
Do not paste hub desk wallets. Subaccounts after $100k volume.

SSH (already extracted):

  cd /opt/rimbaud && sudo bash install.sh
