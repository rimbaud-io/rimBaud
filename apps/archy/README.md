# archy

The version window.

| File | What it is |
| --- | --- |
| `src/main.cpp` | Starts the window and the command line. |
| `src/desk.cpp` | Draws the version. The LEVEL UP button lives here. |
| `archy_db.py` | The ledger. `--bump-g` adds g15, g16, and so on. |

LEVEL UP, from 0.1 to 0.2, is the operator button. `--bump-g` does not do that, and it does not copy code onto another machine.
