Bare-metal rescue USB via ReaR (Relax-and-Recover). This writes a bootable stick. If the PC dies, boot that USB and run rear recover. It does not restore the running machine from here, and it does not close Hyperliquid positions. Docker image layers are skipped. A checkup runs first: the stick must be large enough for the gzip estimate.
